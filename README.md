# مؤسسة بروع التجارية

موقع تعريفي رسمي لمؤسسة بروع التجارية، بهوية بصرية مستوحاة من الشعار (الأسود والذهبي والكريمي)، ويدعم العربية واتجاه RTL.

## التشغيل محليًا

```bash
npm install
npm run dev
```

للبناء والنشر:

```bash
npm run build
```

المجلد الناتج `dist` هو ما يُرفع إلى الاستضافة بعد حجز الدومين.

## تعديل البيانات بسهولة

كل المحتوى القابل للتغيير موجود في:

- `src/data/site.ts`

من هناك يمكن تحديث:

- اسم المؤسسة والسجل التجاري
- أرقام التواصل
- البريد الإلكتروني بعد تفعيل الدومين
- بيانات الموظفين التجريبية
- وصف الخدمات
- رابط الخريطة

## استبدال الصور

ضع الملفات الجديدة في المسارات التالية مع الإبقاء على نفس الأسماء، أو عدّل المسارات في `src/data/site.ts`:

- الشعار: `public/logo.png`
- أيقونة الموقع: `public/favicon.png`
- صور الخدمات: `public/images/services/`
- صور الفريق: `public/images/team/`
- شعارات الشركاء: `public/images/partners/`

بيانات الفريق الحالي تجريبية وقابلة للاستبدال لاحقًا.

## النشر على دومين خاص

1. احجز الدومين ثم اربط الاستضافة بمجلد `dist`.
2. ملفات `_redirects` و `.htaccess` و `vercel.json` مضافة لدعم التنقل بين الصفحات.
3. بعد تفعيل البريد على الدومين، أضفه في `company.email` داخل `src/data/site.ts`.
4. حدّث `company.mapEmbedUrl` بعد اعتماد العنوان الرسمي.
